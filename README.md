# Бот-экзаменатор для музея (Telegram + ВК)

Телеграм и ВК боты, которые проверяют знания кандидатов на стажировку в исторический музей: задают вопрос с вариантами ответа и сразу говорят, угадал человек или нет.

- **[tg_bot](https://t.me/museum_recruiter_bot)** — бот в Telegram
- **[vk_bot](https://vk.ru/club240834241)** — сообщество ВКонтакте с ботом

## Как это работает

Пользователь нажимает «Новый вопрос» — бот выбирает случайный вопрос из базы и присылает его вариантами ответа на кнопках. Пока идёт ожидание ответа, правильный вариант хранится в базе Redis (по ID пользователя) — так бот «помнит», что именно он спросил, даже если процесс перезапустится между вопросом и ответом.

- В **Telegram** бот работает асинхронно на aiogram, переключение между "жду вопрос" и "жду ответ" сделано через FSM (машину состояний).
- Во **ВКонтакте** бот работает через Bot Long Poll (vk_api), логика та же самая, но реализована через последовательные проверки.
- Оба бота используют одну и ту же базу вопросов и один и тот же Redis — можно проходить тест в любом из них.

## Установка

1. Клонировать репозиторий:
```bash
git clone https://github.com/ваш-username/quiz_bot.git
cd museum_quiz_bot
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Создать файл `.env` в папке проекта:
```bash
TG_BOT_TOKEN=токен_телеграм_бота
VK_BOT_TOKEN=токен_группы_вк
VK_GROUP_ID=id_группы_вк
ADMIN_CHAT_ID=ваш_telegram_chat_id
REDIS_HOST=адрес_redis
REDIS_PORT=порт_redis
REDIS_PASSWORD=пароль_redis
QUESTIONS_FILE_PATH=questions_final.json
```

## Как получить токены

**TG_BOT_TOKEN** — токен Телеграм-бота:
- Написать [@BotFather](https://t.me/BotFather) в Telegram
- Отправить `/newbot` и следовать инструкциям
- Скопировать выданный токен

**VK_BOT_TOKEN** — токен вашего сообщества ВКонтакте:
- Зайти в сообщество ВК -> Управление -> Работа с API
- Нажать «Создать ключ», отметить галочку доступа к сообщениям, скопировать токен

**VK_GROUP_ID** — числовой ID вашего сообщества ВКонтакте:
- Скопировать цифры из адресной строки сообщества (например, из ссылки `vk.ru/club240834241` ID будет `240834241`)

**ADMIN_CHAT_ID** — ваш личный chat_id в Telegram:
- Написать любому боту вроде [@userinfobot](https://t.me/userinfobot), он пришлёт ваш ID
- Сюда бот будет слать логи о своей работе и ошибках

**REDIS_HOST / REDIS_PORT / REDIS_PASSWORD** — доступ к базе Redis:
- Зарегистрироваться на [Redis Cloud](https://redis.io/try-free/), создать бесплатную базу
- В настройках базы найти Public endpoint (это host и port через двоеточие) и пароль пользователя
- Либо поставить Redis локально ([инструкция](https://redis-docs.ru/operate/oss_and_stack/install/install-redis/)) — тогда `REDIS_HOST=localhost`, `REDIS_PORT=6379`, пароль не нужен

**QUESTIONS_FILE_PATH** — путь к JSON-файлу с базой вопросов (опционально):
- Если не указать, скрипт по умолчанию возьмёт `questions.json` из корня проекта
- Формат файла — список вопросов с вариантами ответа, см. `questions_final.json`

## Запуск

Запуск бота в Telegram:
```bash
python tg_bot.py
```

Запуск бота ВКонтакте:
```bash
python vk_bot.py
```

Оба бота можно запускать одновременно как два отдельных процесса — они не конфликтуют, каждый работает со своей платформой, но пишут результаты в один и тот же Redis.

## Зависимости

- `aiogram` — асинхронная библиотека для Telegram-бота, включая FSM для состояний диалога
- `vk_api` — библиотека для работы с API ВКонтакте и Bot Long Poll
- `redis` — клиент для хранения активного вопроса пользователя между сообщениями
- `aiohttp` — асинхронная отправка логов в Telegram-чат администратора
- `environs` — чтение переменных из `.env` файла
